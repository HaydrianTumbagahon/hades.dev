# hades.dev

This is my portfolio website built to showcase my work, skills, and personal projects. I built it as a personal brand site where I could present my design and development work in a clean and modern way.

## What I used

- React
- TypeScript
- Vite
- Tailwind CSS
- Lenis for smooth scrolling
- Lucide icons
- React Icons
- GSAP-inspired motion patterns and custom interactions

## What this project is about

This portfolio was designed to feel minimal, bold, and polished while still being personal. It includes:

- a strong hero section
- about and experience details
- skills and capability sections
- selected project cards
- contact CTA and social links
- a dedicated about page with certifications and timeline info

## AI and learning note

I developed this site while practicing my skills and using AI as a learning tool to help me work faster, test ideas, and improve the structure of the project. It was part of my process of building cleaner interfaces and getting more comfortable with front-end work, animation, and responsive design.

## Local development

```sh
npm install
npm run dev
npm run build
```

## Project structure

- `src/App.tsx` — main page layout and content
- `src/index.css` — styling, layout, and animations
- `src/assets/` — local project assets
- `public/images/` — portfolio screenshots and images

## Notes

This project is meant to be a personal portfolio and a working example of my design/development style. I keep updating it as I learn more and refine the way I present my work.
